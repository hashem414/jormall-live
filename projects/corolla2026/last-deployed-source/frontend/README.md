# Frontend Assets

The standalone chatbot UI is served by FastAPI from:

- `app/templates/chat.html`
- `app/static/css/styles.css`
- `app/static/js/chat.js`

The embeddable launcher script is:

- `app/static/js/embed-widget.js`

Example website install snippet:

```html
<script async
  src="/central-trade-auto-co-markazia-toyota-jordan/embed/jormall-chatbot.js"
  data-chat-url="/central-trade-auto-co-markazia-toyota-jordan/?embed=1"
  data-base-path="/central-trade-auto-co-markazia-toyota-jordan"
  data-launcher-label="Chat">
</script>
```
