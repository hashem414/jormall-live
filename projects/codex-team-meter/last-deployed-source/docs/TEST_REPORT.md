# تقرير الاختبار — Codex Team Meter 1.0.0

تاريخ التنفيذ: 20 سبتمبر 2026.

## النتائج المنفذة فعليًا

**29 اختبار Node نجح، صفر إخفاقات، صفر اختبارات متخطاة.** الأمر: `npm test`. البيئة: Linux، Node.js 22.16.0. سجل التنفيذ الكامل في `test-output.txt`. فُحصت صياغة جميع ملفات `.mjs` باستخدام `node --check`.

غطت الاختبارات استخراج العدادات من سجلات اصطناعية، عدم احتساب الكاش والتفكير مرتين، استبعاد التاريخ السابق للتثبيت، الأحداث المكررة، الجلسات المتفرعة، العدادات غير المتوافقة، الأسطر الجزئية والكبيرة، تجاهل ملف اعتماد OpenAI، والمصادقة والتحقق الصارم من الحقول والصلاحيات.

شملت اختبارات التكامل إرسال HTTP حقيقيًا إلى خادم محلي مع SQLite، وتجربة انقطاع وإعادة إرسال ومنع تكرار العد، والتحقق من عدم وجود نص محادثة اصطناعي في الحمولة المرسلة أو طابور المرسل. اختُبر بقاء بيانات SQLite بعد إعادة فتحها. واختُبر مثبت السكيل في مجلد مستخدم Linux مؤقت ومعزول، دون تفعيل مهمة بدء التشغيل: نسخ الملفات، تقييد صلاحية ملف الربط، وعدم السماح بإعادة نسبة الجهاز إلى عضو آخر.

**8 فحوص واجهة نجحت** في Chromium: خطأ تسجيل الدخول، عرض الجدول العربي والمجموع التجريبي، تغيير الفترة، تصدير CSV، تخطيط الهاتف بلا تجاوز أفقي للصفحة، تنزيل ملف الربط وعرض الأسماء المشابهة لـ HTML كنص، إخفاء الإدارة عن العضو، وعدم ظهور أخطاء JavaScript.

فحوص المتصفح استعملت API تجريبيًا داخل صفحة مع بيانات عددية اصطناعية؛ ليست اختبار متصفح متصل بالنشر الفعلي. الوصول المباشر إلى localhost من متصفح هذه البيئة كان محجوبًا بسياسة البيئة، ولم يُتجاوز هذا الحجب. اختبارات HTTP الحقيقية نُفذت منفصلة بواسطة Node. صور `dashboard-preview.png` و`dashboard-mobile-preview.png` هي معاينات اصطناعية موسومة بوضوح، وليست استعمال حساب المستخدم.

## ما لم يُختبر

لم يُربط حساب OpenAI حقيقي أو تُقرأ سجلات المستخدم. توافق صيغة rollout مع إصدار Codex لدى الفريق ما زال يحتاج تجربة قبول بعضو واحد. لم تُشغل مهام Windows Scheduled Task أو macOS LaunchAgent أو Linux systemd فعليًا. لم تُبنَ صورة Docker أو يُنفذ نشر Railway أو إعداد DNS/TLS أو اختبار عنوان عام. لم يُجر تدقيق أمني مستقل أو اختبار ضغط أو تعافٍ إنتاجي.

تحذير SQLite التجريبي الظاهر في سجل Node 22.16.0 متوقع من ذلك الإصدار؛ ليس إخفاق اختبار. Dockerfile يختار Node 24 لكنه لم يُشغّل هنا.

## شرط القبول قبل التعميم

نشر خدمة واحدة وقرص دائم وعنوان HTTPS، ثم إضافة عضو واحد وتثبيت المرسل في بيئة Codex الفعلية. نفذ مهمة محلية جديدة، وتحقق من زيادة العدادات ومن بقاء المحادثة خارج الحمولة. أعد المزامنة للتحقق من عدم التكرار، ثم اختبر الانقطاع والاستعادة. أضف عضوًا ثانيًا فقط بعد فصل النسب والأسماء بنجاح.

لا تفسر مجموع توكنز الاختبارات أو نسبها على أنه تحقق من خصم باقة Pro. هذا المنتج يقيس التوكنز المحلية المرصودة فقط، ويعرض لقطات حدود الحساب منفصلة عند توفرها.
